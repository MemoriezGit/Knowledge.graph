Conversation

This is your second brain. Tell it something and it will remember — it builds the graph behind this text as you talk.

Try: “Remember that I'm learning Portuguese and my tutor is Ana, Tuesdays at 7.”

How to use this

Just talk to it

Tell it things the way you'd tell a person. It decides what's worth keeping, files it as connected memories, and says the answer out loud.

  • “Remember my sister Priya's birthday is 3 June.”
  • “I decided to switch the project to Postgres because of the JSON queries.”
  • “What do you know about my running training?”
  • “How is Ana connected to Lisbon?”

Reading the graph

Every dot is a memory, every line a connection. Bigger and brighter means more important. Click any dot to inspect it. The camera flies to whatever it's talking about.

Shortcuts

Connected apps

You can also talk to this brain from Claude or ChatGPT — it'll answer out loud here and the graph will grow while you watch. Run npm run setup to connect them.
