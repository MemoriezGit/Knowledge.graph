# Owner Decision: Knowledge.graph Becomes a Donor Repository

**Decision date:** August 1, 2026  
**Owner:** Mike  
**Status:** Authoritative

## Decision

The owner has ended the strategy of maintaining HC Vault, Continuum OS, and Knowledge.graph as separate products for resale.

Knowledge.graph is no longer an independent personal brain or authoritative memory store. It is a donor implementation whose strongest graph, AI-memory, recall, and interaction capabilities may be migrated into one private, owner-only Life OS hosted in `MemoriezGit/hc-vault` during consolidation.

## Donor capabilities

Knowledge.graph's strongest contributions may include:

- AI-controlled memory tools
- Graph focus and camera behavior
- Hybrid recall concepts
- Node and edge interaction patterns
- Live graph updates
- Graph rendering and label behavior
- Claude and ChatGPT integration concepts

## Restrictions

Until consolidation is complete:

1. Do not create new authoritative personal memories here.
2. Do not maintain a second production graph or memory store.
3. Do not continue independent product-surface development.
4. Do not describe this repository as the owner's final second brain.
5. Do not copy the entire repository into HC Vault.
6. Migrate capabilities only through reviewed, incremental integration work in HC Vault.
7. Preserve useful tests, architecture evidence, and implementation history for reference.

## End state

After required capabilities, evidence, and history have been preserved in the unified Life OS, this repository should be archived. It must not remain an independently running personal brain, graph authority, or dashboard.
